# Planning method

## Phases before an exam (backward plan)

| Time to exam | Focus | Mix |
|---|---|---|
| > 6 weeks | Keep up with lectures: process each lecture within 48 h (summary + 10–20 cards) | 70% new material, 30% review/practice |
| 6–3 weeks | Close gaps: all topics touched once; past-paper style problems per topic | 40% new / 60% practice |
| 3–1 weeks | Consolidate: interleaved problem sets, error-log drills, first full mock exam | 10% new / 90% practice + review |
| last 7 days | Second mock under exam conditions, weak-topic drills, cheat sheet if allowed | practice + review only |
| last day | Light review of cards and the summary sheet; sleep | no new material |

## Time estimates (adjust after the first week)

| Activity | Typical time |
|---|---|
| Process one 90-min lecture (read, summary, cards) | 60–90 min |
| Flashcard review | 1 min per 2–3 due cards |
| One core problem (quantitative) | 10–20 min |
| One written answer (humanities, 500 words) | 45–60 min |
| Mock exam | real duration + 50% for self-marking |
| Reading for a seminar | 6–10 pages per 30 min (dense theory: less) |

## Spacing pattern for a new topic

Learn on day 0 → review day 1 → practice day 3 → review day 7 → mixed practice day 14 → mock. The
Leitner schedule in `progress.json` handles flashcards; the planner schedules the practice sessions.

## Weekly shape (example, 10 h/week, 45-min sessions)

- Mon: 2 × 45 min Module A (new) + 10 min cards
- Tue: 45 min Module B (practice) + 10 min cards
- Wed: 2 × 45 min Module A (practice, interleaved) + 10 min cards
- Thu: 45 min Module B (new)
- Fri: 45 min error-log drill (both) + 10 min cards
- Sat: 90 min mock section or problem sheet
- Sun: rest

## Event naming

`<Module short> · <topic> · <method>`, e.g. `LA · Eigenvalues · worked examples`. Put the goal and the
skill to use in the description: "Goal: 6 problems from sheet 3. Ask Claude: practice drill eigen."
